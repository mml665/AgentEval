# AgentEval 构建状态

**版本：** 0.5.0 / 状态验证、轨迹深度、校准与专项指标

**日期：** 2026-11-03

当前已实现前后端闭环与可靠执行协议；完整 MVP 的安全、运维及真实裁判校准尚未全部验收。

## 0.5 本轮交付

- EnvironmentAdapter + 独立 state_assertion，执行器读取真实 SQLite 状态，保存重置前快照；输出正确但未写表的反例判失败。
- 轨迹支持禁止步骤/工具、重复与循环规则、条件分支、替代路径、失败后恢复时序及状态转换白名单。
- 工具评分显式处理观测完整性，支持一一 ID 映射和显式同名第 n 次匹配，增加缺失/失败/重复/部分轨迹边界验证。
- 评分器增加粒度 × 质量维度 × 机制元数据；Judge 可显式选择 E2E、轨迹、工具或组件证据。
- 分项得分、覆盖率、状态/工具/轨迹/可靠性/Usage/Judge 指标及版本差异；可选 P95、工具错误率、评分覆盖门禁，样本不足不通过。
- Judge 种子标签、固定批次校准 API / 前端面板 / CLI，报告混淆矩阵、一致率、缺失/错误与重复波动；不覆盖历史评分。
- SQLite FTS5 / BM25 与独立 TF-IDF 重排；可配置 HTTP 组件，独立进程验证 Recall/MRR/NDCG，包括检索未命中反例。
- 0.5 数据迁移与 PRD/设计状态说明；详细契约见 [0.5 验收说明](V0.5_ACCEPTANCE.md)。

这些集成样例和开发者种子标签不能替代两个真实业务项目及独立人工标注集的验收；真实模型尚未调用校准。

## 默认配置

| 项目 | 默认与边界 |
|---|---|
| 模式 | local；Compose 使用 celery |
| 项目执行上限 | 8，跨 Worker 共享，不是全局机器资源上限 |
| Run 执行上限 | 4，可配置 1–16 |
| 项目评分批次并发 | 1，与 Agent 容量分开 |
| 租约 / 心跳 | 30 秒 / 租约的三分之一 |
| 重试 | 默认 0、最多 2，仅显式 read_only |
| Judge | 每评分最多 2 次；Run 默认 100 次，含中断和重评 |
| 超时 | Agent 默认 30 秒、最大 300；Judge 默认 15 秒、最大 60 |
| 请求/输出 | API 2 MiB、Agent 输出 1 MiB、Judge 响应 64 KiB |
| 管理员处置 | 团队 token + 独立 Admin token + 审计理由 |
