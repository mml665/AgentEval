# 团队身份、会话与旧 API 兼容设计（批次 B 输入）

日期：2026-11-04。依据 AE-001～003。**设计待实现，不代表 0.8 已具备个人身份、项目权限、会话或完整脱敏。** 当前仍是可信部署共享 Token，项目仅是组织边界。

## 1. 最小身份与授权

首发采用部署内成员账户，不默认引入 SSO。新增 User（稳定 UUID、启用状态）、ProjectMembership（用户/项目唯一、evaluator/viewer）、MachinePrincipal（项目白名单及 read/evaluate/admin 能力）、Session、CredentialVersion 和审计 actor 引用。管理员是部署级角色，人工释放未知占用仍要求专项管理能力和非空理由。

所有业务请求先解析服务端 Principal，再通过统一授权依赖检查动作和资源归属；只读者不得写入。列表仅查询授权项目，空白名单绝不解释为全项目。任务、批次、执行、Trace、导出、Issue、回归版本和发布报告按实际外键链追溯项目；比较需核对两侧运行。跨项目猜测 ID 返回 404；已知动作无权限返回 403。前端按钮只是交互提示，不是授权依据。

Issue.owner 从自由文本迁移为可空 assignee_user_id，并保留 legacy_owner 原文；管理员只能在有效项目成员中分配。历史操作 actor 保留 legacy_team/unknown，不能从负责人字段反推操作者。所有新写操作保存 Principal ID、动作、资源、修订号及必要理由，不保存凭据。

## 2. 会话与机器调用

浏览器使用服务端持久化的随机不透明短期会话，数据库保存令牌摘要及闲置/绝对到期、撤销和用户状态；不把长期部署 Token 转存浏览器。Cookie 使用 HttpOnly、SameSite，HTTPS 使用 Secure；仅显式本机开发模式允许 HTTP。写操作同时校验 Origin 和绑定会话的 CSRF 令牌。反向代理终止 TLS 的可信代理与外部 Origin 必须显式配置。

GET 会话恢复接口返回最小身份和授权项目。会话有效时刷新恢复页面、项目和允许的 URL 查询；资源失效/无权限明确提示，不静默选另一项目。登出、禁用用户、撤销会话立即使后续请求失效，清空前端内存缓存与敏感草稿。服务端草稿按 User/Project 隔离，另行实现 AE-111。到期时间由部署方配置，测试覆盖闲置及绝对到期。

SDK/CI 保留 Bearer 机器令牌，独立于浏览器会话；服务端保存摘要、项目范围、能力、到期和撤销状态，生成时仅显示一次。不把旧共享 Token 自动解释为某个真实用户。新机器调用的运行发起人保存 Principal，旧运行保留“共享团队身份/未记录个人”。

## 3. 管理员初始化与迁移

1. 停止旧进程，备份数据库、密钥存储及旧发布包；先在隔离副本演练迁移。
2. 通过部署侧 CLI 一次性初始化首位管理员；初始秘密由本机交互/受控文件提供，不经公开 HTTP 初始化接口，不写日志。
3. 管理员配置首批成员、项目成员关系、机器令牌和凭据引用。没有分配的项目默认拒绝。
4. 过渡期提供显式 legacy_token_enabled 开关，原 AGENTEVAL_API_TOKEN 只作为历史团队 Principal，单独记录审计来源；这是管理员级兼容模式，界面必须显示迁移风险。完成 SDK/Worker 切换后关闭并撤销旧 Token，不能默默长期保留双通道。
5. 升级说明列出环境开关、机器令牌轮换、退出/撤销以及回滚前版本对新表的兼容限制。个人审计字段可空且独立追加，不改写历史证据和判定；回滚仅恢复隔离验证过的发布包与成套备份。

## 4. HTTP 凭据与插件环境

AgentVersion 配置仅保存有项目归属的 CredentialVersion 引用、鉴权方式和 Header 名；值由服务端凭据提供方读取。界面不回显，成员不可枚举平台任意环境变量。运行 Manifest 冻结引用和不可变版本标识，不冻结明文。撤销后新调用/显式重跑失败并给出换用新凭据版本的动作；旧证据重评不重新调用 Agent，也不需要复活凭据。

HTTP 连接检查拆分为地址、网络、鉴权、协议和观测；未执行的步骤为未验证。HEAD 405 仅说明此方法不支持。独立“测试调用”动作要求明确测试用例和环境，遵守原允许清单、超时、禁止跨目标重定向及有副作用限制。401/403、连接、超时、无效 JSON、协议和业务失败分别编码，不回显请求头。

插件仍必须经可信部署注册。子进程仅获得运行所需 OS/Python 路径、区域/证书变量及显式允许的项目凭据/运行上下文；不继承平台 API、数据库、Redis、Judge 等无关秘密。依赖额外环境的既有插件需显式声明并有启动预检。环境最小化不是不可信代码沙箱。

## 5. 原始证据、展示与留存

原始证据保持受保护存储及原始哈希/来源校验；普通展示使用版本化字段路径和内容脱敏策略产生派生视图，派生视图另有摘要及规则版本，不能让脱敏内容冒充原始哈希验证通过。原始读取需专项权限和审计。嵌套字段、普通文本、URL、错误、Trace、日志和导出共用规则。

留存策略、容量观测、归档/恢复按项目配置。任何发布快照或固定报告引用的证据均有引用保留约束，不能直接按创建时间自动删除。先交付归档清单、引用校验及隔离恢复，保留期限和容量目标由部署方确认。不能在现有备份或证据表上开展破坏性演练。

## 6. 批次 B 退出条件

角色矩阵覆盖管理员、评测、只读及两项目；直接 API/Trace/导出 ID 越权测试，机器令牌范围、会话过期/撤销/退出、真实操作者和成员分配测试全部通过。HTTP 鉴权夹具覆盖失效/拒绝/超时/协议错误和秘密不泄漏，插件环境测试证明无无关平台秘密。真实 Agent 和当前发布包恢复/灾备、真实 Judge 校准仍归 AE-004，不能由这些协议测试替代。
