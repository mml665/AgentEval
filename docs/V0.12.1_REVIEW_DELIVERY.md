## 接口与升级

- `GET /api/v1/quality/scope-selection/{project_id}` 可传 `candidate_run_id`、`candidate_batch_id` 及基线对应字段，直接解析固定标识并返回首屏选项。四个主选择器各返回最多 50 项。
- `GET /api/v1/quality/scope-options/{project_id}` 的 `kind` 可选 `agent`、`version`、`benchmark`、`run`、`batch`。后续页使用 `next_offset`，每页最多 100 项。批次列表限定在指定运行且只列已完成批次。范围、工作台、比较和发布查询校验运行、批次、版本和数据集的对应关系。
- `GET /api/v1/onboarding/requests/{request_key}` 继续支持指定项目查询。省略项目时仅部署管理员可查询本人创建的向导回执，返回最小运行定位字段。首次建项目且尚无项目草稿时，当前页面可查询、重试或返回修改。跨刷新恢复完整配置使用已选项目的个人草稿。
- 迁移头为 `0010`。已有 API 和历史证据继续可读。按既有引擎版本规则，用旧批次生成新的当前发布建议需要重评。已有报告保留生成时的快照。

## 验证口径

- 本地回归覆盖 192 项 Python 与 19 项浏览器用例，前端生产构建通过。新版范围合同同时纳入团队集成测试。
- 用隔离 SQLite 库生成 10,051 条运行与 10,051 个批次，按 ID 打开早于分页窗口的运行。实测范围选择接口 1 次请求、1,305 字节、84.6 毫秒。浏览器在同一固定范围内从异常页切换到工作台和发布页，共两次导航，额外范围选项与历史列表请求为 0。证据位于 `.build/workflow-scope-navigation.json`。
- 浏览器覆盖语法破坏、文件替换、同版本相反结果和多批次、丢失响应、草稿恢复后同键重试、首次项目回执及本地日期边界。后端覆盖事务提交前中断和回滚、回执创建者隔离、无完成批次的运行及大历史分页。
- 两个真实业务 Agent、Judge 独立人工标签与模型校准、目标用户试用及生产容量继续按产品文档安排。
